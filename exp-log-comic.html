深夜的數學課本

小莊

明天就要模擬考了,課本上一直出現「log」,到底 log28 是什麼意思啦!

貓頭鷹教授

別慌!對數其實只是在問一個很簡單的問題:「2 要自乘幾次才會變成 8?」答案是 3 次,所以 log28 = 3。

小莊

咦...聽起來好像沒有想像中可怕?

貓頭鷹教授

一點都不可怕!跟我來,從指數規則開始,五分鐘後你就能自己解題了。

概念一

先複習:指數的基本規則

在認識對數之前,要先跟指數（次方）打好關係——所有對數規則其實都是指數規則「倒過來看」而已。

乘法
am×an=am+n
除法
am÷an=am−n
a ≠ 0
乘方
(am)n=amn
零次方
a0=1
a ≠ 0
負指數
a−n=1/an
分數指數
am/n=n√(am)
a > 0
指數函數 f(x) = aˣ

當 a > 1 時圖形一路往上衝（遞增）;當 0 < a < 1 時圖形一路下滑（遞減）。不管哪一種,曲線永遠會通過 (0, 1) —— 因為任何數的 0 次方都是 1。

概念二

對數的誕生:把指數問題倒過來問

指數方程式 ax = N 是在問「答案是多少」;而對數,就是在問「指數 x 是多少」。這兩件事是同一件事的兩種寫法:

logaN=x⟺ax=N
條件:a > 0、a ≠ 1、N > 0（這叫做「真數」,一定要大於 0！）
貓頭鷹教授

把 logaN 唸成:「a 的幾次方會等於 N？」答案就是 x。所以 log28 就是在問「2 的幾次方 = 8」,答案是 3。

特例一
logaa=1
特例二
loga1=0
特例三
logaan=n
概念三

對數的三大運算律

前提:M > 0、N > 0、a > 0 且 a ≠ 1。

積化和
loga(MN)=logaM+logaN
商化差
loga(M/N)=logaM−logaN
次方提出
loga(Mk)=k·logaM
陷阱警報!加減法不能直接拆對數

loga(M+N) ≠ logaM + logaN —— 這是最多考生失分的地方,對數的運算律只對「乘除」成立,對「加減」無效！

小莊

那要怎麼記住哪個是加、哪個是減啊？

貓頭鷹教授

回想指數規則就好:am×an=am+n——相乘時指數相加,所以對數（反過來問指數）也是相乘變相加。規則永遠是對稱的！

概念四

換底公式:讓任何底都變好算

計算機通常只有「以 10 為底」的 log 和「以 e 為底」的 ln 兩個按鍵,遇到 log37 這種奇怪的底該怎麼辦？換底公式就是救星:

logab=logcblogca
c 可以自由選擇(通常選 10 或 e),但分子分母不能顛倒！
口訣:換底公式「新底在下面」

不管換成哪個底 c,新的底 c 永遠寫在分母。分子放你原本要求的「真數」,分母放你原本的「底」。

概念五

指數函數 vs 對數函數的圖形

這兩個函數互為「反函數」——把 y = aˣ 的圖形沿著 y = x 這條線對摺,就會得到 y = logax 的圖形。

指數函數 y = aˣ ・恆過 (0,1)
對數函數 y = logax ・恆過 (1,0)
指數函數定義域
所有實數
對數函數定義域
x > 0（真數限制！）
概念六

對數在生活中無所不在

對數最厲害的地方,是能把「差距超級大」的數字壓縮成好懂的小刻度。

pH

酸鹼值 pH

pH = −log[H⁺]。氫離子濃度每差 10 倍,pH 值只差 1。這就是為什麼 pH 從 7 到 4 感覺差距不大,實際酸度卻差了 1000 倍。

M

地震規模

地震規模用對數計算,規模每增加 1 級,釋放的能量約增加 31.6 倍——規模 6 和規模 8 之間,能量差距是天文數字。

A

複利成長

本金翻倍要幾年？公式 A = P(1+r)ᵗ 中,求時間 t 一定要靠對數:t = log2 ÷ log(1+r)。

實戰演練

兩個經典例題,看教授怎麼解

指數方程式

2x+1 = 32 ⟶ 2x+1 = 25 ⟶ x+1 = 5 ⟶ x = 4
關鍵技巧:把兩邊都寫成「相同的底」,指數就能直接對消。

對數方程式

log2x + log2(x−2) = 3
Step 1 先設定義域:x > 0 且 x−2 > 0,所以 x > 2。
Step 2 積化和:log2[x(x−2)] = 3 ⟶ x(x−2) = 2³ = 8。
Step 3 解一元二次:x²−2x−8 = 0 ⟶ (x−4)(x+2) = 0 ⟶ x = 4 或 x = −2。
Step 4 檢查定義域:x = −2 不符合 x > 2,捨去。答案只有 x = 4。
解對數方程式,永遠先檢查定義域！

沒檢查真數是否大於 0,就可能把不合法的「增根」當成答案——這是大題最容易被扣分的地方。

小莊的錯誤 vs 正確解法

小莊的答案

log(3+7) = log3 + log7,所以答案是 log3+log7！
